# 📦 Smart Inventory & Billing System

A simple, responsive web application for managing product inventory, tracking stock, and generating billing totals using **HTML, CSS, and JavaScript**.

## 🌐 Live Demo

[Visit Smart Inventory & Billing System](https://kit25csecwilliamv-cmyk.github.io/smart-inventory-system/)

## 📌 Project Overview

The Smart Inventory & Billing System helps users manage products and monitor inventory through a clean, user-friendly dashboard. It provides basic product management, automatic stock calculations, and billing functionality directly in the browser.

This project uses frontend technologies only, without requiring a Java backend or database.

## ✨ Features

- 📊 **Dashboard** — View total products, stock units, inventory value, and sales.
- ➕ **Product Management** — Add products with names, categories, prices, and stock quantities.
- 🔍 **Product Search** — Find products quickly.
- 📦 **Stock Tracking** — Monitor available inventory.
- 🧾 **Billing System** — Select products, enter quantities, and calculate bill totals.
- 💰 **Automatic Calculations** — Calculate inventory value and sales totals.
- 📉 **Stock Updates** — Automatically reduce stock after completing a sale.
- 💾 **Browser Storage** — Save product data and sales totals using LocalStorage.
- 📱 **Responsive Design** — Adapt the interface to desktop and mobile screens.

## 🚀 How to Run the Project

### Option 1: Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `docs/index.html` in a web browser.
4. Start adding products and testing the billing features.

For easier development, you can use the **Live Server** extension in Visual Studio Code.

### Option 2: Run Online

Visit the deployed website:

https://kit25csecwilliamv-cmyk.github.io/smart-inventory-system/

## 💻 Usage

1. Open the dashboard.
2. Enter the product name, category, price, and stock quantity.
3. Click **Add Product**.
4. Search for products or review inventory statistics.
5. Select a product and quantity in the billing section.
6. Click **Add to Bill** to calculate the subtotal.
7. Click **Complete Sale** to update stock and sales totals.
